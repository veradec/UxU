Welcome to UxU

Yes! UxU is a File Hosting service, but not in it's traditional sense. There is no Upload Button. You need to move to the cultured way of doing it -- using curl.

curl -X POST -F "file=@file.png"

and the reponse will be a link with your Filename (sanitized ofcourse)

https://uxu.veradec.xyz/{random_string}/file.png

something of this sorts and you can share the link too!

No Tracking or No Looking, I promise | You too can host it with this git repo
